# 常见问题

[← 回到首页](../README.md)

按遇到的现象查找。

**手机提示连不上。** 局域网直连时确认手机和电脑在同一个 Wi-Fi，并且防火墙询问时选了“允许”（没选的话到“Windows 安全中心 → 防火墙 → 允许应用通过防火墙”里勾上 python）。公网隧道的地址在退出程序或重启电脑后会变，需要重新扫码；更新程序不会改变地址。

**电脑关闭后手机停在 1033 错误页。** 0.5.2 起，App 遇到隧道错误会自动回到工作台并提示重新扫码。正在查看终端时也会独立检查连接；短暂的网络波动先重试，连续两次检查失败才返回。请重新打开电脑端，再扫描新的二维码。

**手机更新提示 “file still open”。** 这是 0.5.4 之前的更新器在提交 APK 前还占用安装流导致的。旧版内部的更新器无法通过下载新版本修复自身，请从发布页手动下载最新 APK 覆盖安装一次，原有设置会保留；之后可继续使用 App 内更新。

**工作台里一个任务一直显示“已完成”。** 这个标记保留到你点开那个终端为止。在工作台点它，或在这台电脑的列表里点它，都算看过。

**列表里没有“新建 Claude Code”。** 按钮只显示电脑上能找到的工具。先在电脑的命令行里确认 `claude` 或 `codex` 能运行，再重新打开 Remote CLI。

**输入后要等一下才显示。** 终端优先使用 WebSocket 持续连接，输入和输出实时传输，连续按键不用逐次等待上一条请求完成。公网仍有网络往返延迟；同一个 Wi-Fi 下用局域网直连最快。连接不支持 WebSocket 时会自动切换到 HTTP，Cloudflare 临时隧道会跳过不能及时传输的 SSE。

**电脑上打开着的对话，为什么有时不能接到手机终端？** 点开对话就能在对话窗口里查看和发消息，对话留在电脑上，一般不需要接到手机终端。确实要接过来时（长按卡片），得先结束电脑上正在用这段对话的程序。电脑端只有在确认了是哪个进程在用它之后才会去结束，这时显示“接到手机终端（关闭电脑上的）”。由 Codex 桌面应用或编辑器打开着的对话，它们的后台可能同时管着好几段对话，手机不能替你关，所以会请你先在那个应用里结束；Codex 还可以“另开一份到手机终端”，用 `codex fork` 带着此前的内容新开一段，之后各自继续。已经结束的对话用 `codex resume` 恢复。

**电脑上只开着一段对话，手机为什么还列出别的？** Codex 桌面应用或编辑器可能还占着以前的对话，另一个远程终端也可能在后台运行着。它们折叠在“电脑上闲置或被占用的对话”里，标着“被电脑上的应用占用”“被另一个远程终端占用”或“被电脑上的程序占用”，不算在电脑上打开着的数量里，程序也不会去结束它们。

**想在电脑上用手机开的终端，要交接吗？** 不用。0.8.0 起，在电脑端“活动”页双击那个终端，电脑上会打开一个窗口，里面就是同一个终端，手机和电脑都能看、都能输入。原来的“结束手机终端，在电脑的命令行窗口里接着用”还在，叫“转成独立窗口”，转之前会重新核对进程和对话编号，核对失败会保留原终端并说明原因。

**启动后马上结束。** 终端画面和退出代码会保留；检查画面中的 CLI 提示，例如登录状态、命令支持或工作目录。会话扫描遵循 `CODEX_HOME`，旧锁文件不会仅因存在而被显示为运行中。

**换了连接方式，之前开的终端还在吗？** 在。1.0.9 起，在公网隧道、局域网和自有中转之间切换不会结束终端，手机重新扫码后，工作台的各段列表里还是原来的终端，名字和最近的画面都在。用自有中转时，服务器上的中转也要更新到 1.0.9 或更高版本，见[自己部署中转](SELF_HOSTING.md)。

**端口 8722 被占用。** 退出程序后，把 `%LOCALAPPDATA%\RemoteCli\config.json` 里的 `Port` 改成别的数字再打开。

**终端页为什么没有话筒按钮？** 话筒用的是手机系统自带的语音识别。很多国内品牌的手机没有这个组件，按了也不会有反应，所以 1.0.0 起在这样的手机上不再显示它。请点输入框，用输入法键盘上的语音键说话，效果是一样的。

**开了任务提醒却收不到通知，或者来得晚。** 先确认系统设置里允许了 Remote CLI 的通知。1.1.0 起通知栏里不再有常驻的通知，App 由系统大约每分钟唤醒一次去查看，所以提醒会晚几十秒到一分钟，手机深度休眠时更久。有些手机不允许应用在后台被唤醒，需要在系统设置里允许 Remote CLI 自启动，并把电池优化设为“不限制”。提醒只在 App 离开前台之后工作，并且只提醒离开之后新出现的情况。

**公共中转安全吗？** 每台电脑在公共中转上有一个只属于自己的空间，密码只有这台电脑和扫过码的手机知道，别的使用者看不到你的终端，中转上也没有可供查看的使用者列表。但终端的输入和输出要经过那台服务器，它的运营者在技术上能够看到。处理敏感内容时请用局域网直连、公网隧道，或在自己的服务器上装一个中转。

**公共中转不见了，或者换了。** 公共中转来自项目维护的一份清单，会增加、更换或撤掉。正在用的那个被撤掉后，窗口会提示它已从列表中移除：在“公共中转”里换一条，或改用别的连接方式，然后手机重新扫码。一个月没有用过的空间会被中转清理，下次使用时电脑端自动申请新的，地址会变，手机需要重新扫码。
