# 锦鲤池塘主题

`terminal/skins.js` 是页面配色与主题选择的入口。只有选择 `pond` 时才加载 `pond.js` 和本地资源；普通主题不启动背景绘制。Android 原生列表使用 `Kit.java` 的对应配色，对话、终端和电脑提供的内嵌页面显示池塘。

Android 1.7.5 起把整套 `web/` 作为 APK 资源提供。公共中转服务器的旧页面不会覆盖 App 内的新主题菜单；浏览器单独访问时仍使用服务器页面。终端曾单独选择其他主题时，需选“跟随 App 外观”或直接选池塘。

`PondTheme` 管理一个页面的池塘、画布、暂停按钮和事件监听。切换到其他主题时取消绘制、释放画布和监听；页面隐藏、失焦或离开时停止绘制，返回后恢复。暂停选择保存在当前电脑页面的本地存储中，系统减少动态效果时只绘制静态画面，高对比度模式隐藏装饰。

鱼群模拟与字符渲染来自 MIT 许可的 [ascii-pond](https://github.com/stqfdyr/ascii-pond)，固定提交 `822a3c95167f79f0905720a2e6793cb4a64eda55`。`vendor/ascii-pond` 保留三个原始源文件及许可证，不使用 CDN、外部字体或构建依赖。仅调用 `Pond`、`PondRenderer` 和 `koi`，页面生命周期由本项目管理，不调用上游的全局鼠标跟随、点击投食或自动挂载入口。

池塘主题复用终端的 GPU 平滑滚动层；移动的行下面使用不透明底色，避免半透明快照透出旧文字。滑动期间优先清楚显示终端内容，结束后恢复背景；没有可用 GPU 时保留逐行滚动。切换主题时清空滚动快照。

深色水面承载暖色锦鲤，文字和操作仍是视觉重点；沿用既有居中内容框、手机安全区、字体与间距。画布不接收事件，不改变输入、选择和滚动。长回复、输入框和导航有深色底，终端使用透明背景保留池塘，但字符与 ANSI 指定背景正常绘制。动画上限为每秒 12 帧，像素密度为 1，保留两条成鱼；依据实际绘制耗时继续降低频率，调度目标是将背景计算控制在主线程约 5% 的时间内，而非设备性能保证。帧间使用定时器，避免每个屏幕刷新周期空转；相同尺寸不重复分配画布。

手指按住、滑动、惯性滚动、键盘输入及编辑期间停止模拟和绘制；最后一次交互后至少空闲 1.2 秒才恢复。手指一直按住时不会自动恢复。用户暂停和系统减少动效仍优先，关闭主题会清理监听与定时器。

验收入口：`python tests/pond_ui_check.py <chrome.exe> <输出目录>`。覆盖主题选择、真实终端渲染、对话布局、窄屏和桌面、暂停、减少动效、主题切换、背景输入穿透和资源加载。

性能与触控：`python tests/pond_performance_check.py <chrome.exe> <输出目录>`，使用 CPU 降速 4 倍的浏览器近似较慢设备，记录绘制耗时并检查 DOM/WebGL 终端历史滚动、交互期间停绘、空闲恢复和卸载。浏览器测量不代表 Android 真机表现。
