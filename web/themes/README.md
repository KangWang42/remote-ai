# 锦鲤池塘主题

`terminal/skins.js` 是页面配色与主题选择的入口。只有选择 `pond` 时才加载 `pond.js` 和本地资源；普通主题不启动背景绘制。Android 原生列表使用 `Kit.java` 的对应配色，对话、终端和电脑提供的内嵌页面显示池塘。

Android 1.7.5 起把整套 `web/` 作为 APK 资源提供。公共中转服务器的旧页面不会覆盖 App 内的新主题菜单；浏览器单独访问时仍使用服务器页面。终端曾单独选择其他主题时，需选“跟随 App 外观”或直接选池塘。

`PondTheme` 管理两个图片节点、暂停按钮和事件监听。图片在第一次启用时异步解码，同一页面切换主题时复用，尺寸固定为 192×320，每张解码像素约 240 KiB。停用时移除节点和监听、取消恢复定时器；页面隐藏、失焦或离开时停止移动，返回后恢复。暂停选择保存在当前电脑页面的本地存储中，系统减少动态效果时显示静态画面，高对比度模式隐藏装饰。

字符锦鲤来自 MIT 许可的 [ascii-pond](https://github.com/stqfdyr/ascii-pond)，固定提交 `822a3c95167f79f0905720a2e6793cb4a64eda55`。`vendor/ascii-pond` 保留三个原始源文件及许可证。`tools/pond_sprites.py` 使用固定随机种子和该渲染器，在构建准备阶段生成 `assets/koi-amber.png` 与 `assets/koi-pearl.png`；生成命令为 `python tools/pond_sprites.py <chrome.exe> <工作目录>`。提交生成图供两端打包，无需终端启动时生成；运行页面不导入模拟器，不运行鱼群计算或 Canvas 绘制循环，不使用 CDN。

池塘主题复用终端的 GPU 平滑滚动层；移动的行下面使用不透明底色，避免半透明快照透出旧文字。滑动期间优先清楚显示终端内容，结束后恢复背景；没有可用 GPU 时保留逐行滚动。切换主题时清空滚动快照。

深色水面承载暖色锦鲤，文字和操作仍是视觉重点；沿用既有居中内容框、手机安全区、字体与间距。图片不接收事件，不改变输入、选择和滚动。长回复、输入框和导航有深色底，只有池塘主题开启终端透明绘制。两条锦鲤使用缓存纹理和 CSS transform 缓慢游动，保留字符外观；不再模拟摆尾、鱼群行为和尾流。动画不再依赖每帧 JavaScript，合成成本仍取决于设备。

手指按住、滑动、惯性滚动、键盘输入及编辑期间停止移动；最后一次交互后至少空闲 1.2 秒才恢复。手指一直按住时不会自动恢复。高频输入只保留一个恢复定时器。用户暂停和系统减少动效仍优先。

验收入口：`python tests/pond_ui_check.py <chrome.exe> <输出目录>`。覆盖主题选择、真实终端渲染、对话布局、窄屏和桌面、暂停、减少动效、主题切换、背景输入穿透和资源加载。

性能与触控：`python tests/pond_performance_check.py <chrome.exe> <输出目录>`，使用 CPU 降速 4 倍的浏览器近似较慢设备，记录空闲脚本耗时并检查 DOM/WebGL 终端历史滚动、交互期间静止、纹理复用、空闲恢复和卸载。`tests/terminal_render_check.py` 使用相同参数检查三种主题、颜色、持续拖动和滚动缓存失效。浏览器测量不代表 Android 真机表现。
