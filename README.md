# Remote AI

**用 Android 手机接着操作电脑上的 Claude Code、Codex 和终端。**

电脑上问一句，手机上接着问一句，对话仍在原来的应用里。离开电脑后，可以查看进度、发送指令、处理确认请求，也可以打开完整终端继续工作。

Remote AI 由电脑端程序和 Android App 组成。任务在电脑上运行，手机断网、锁屏或退出 App 不会结束任务；重新连接后可继续查看和操作。它使用电脑上已有的工具、模型账号与配置，不提供模型服务，也不托管模型账号。

## 下载与安装

在 [最新 Release](https://github.com/KangWang42/remote-ai/releases/latest) 下载两个安装包：

| 设备 | 文件 | 要求 |
| --- | --- | --- |
| Windows 电脑 | `RemoteCli-Setup-x.y.z.exe` | Windows 10 / 11，64 位；安装到当前用户目录，无需管理员权限 |
| Android 手机 | `RemoteCli-Android.apk` | Android 8.0 及以上 |

Windows 安装包尚无发布者代码签名，系统可能提示“未知发布者”。Android APK 使用固定密钥签名以支持覆盖更新，首次安装需允许对应来源安装应用。

### 1. 安装电脑端，选择连接方式

打开 Remote AI，在“连接”页选择线路，等待二维码出现。

| 场景 | 选择 | 说明 |
| --- | --- | --- |
| 手机与电脑在同一可信网络 | 局域网 | 延迟低；首次运行按需允许 Windows 防火墙访问 |
| 外网连接，没有服务器 | 公网隧道 | 下载隧道程序后获得临时 HTTPS 地址，无需注册账号 |
| 希望保持固定地址 | 公共中转 | 选择已有线路；内容经该中转服务器传输 |
| 希望使用自己的服务器 | 我的中转 | [部署中转](docs/SELF_HOSTING.md)后添加，可保存多条线路 |

<p align="center"><img src="docs/images/windows.png" alt="Windows 电脑端的连接方式与配对二维码" width="64%"></p>

### 2. 手机扫码，打开已有对话

打开 App，点“扫码添加电脑”，扫描电脑端二维码。工作台会列出电脑上的 Claude Code、Codex 对话和终端。点开已有对话即可查看，发送、确认和停止操作按当前工具提供的能力显示。

**已有对话不必先加入项目。** 即使文件夹不在 Remote AI 的项目列表里，电脑端已发现且仍打开的对话也可以交互。闲置的桌面对话可在“电脑上闲置或被占用的对话”中找到。

### 3. 添加项目，用于新任务和文件查看

在电脑端“项目”页添加文件夹，或从“终端项目”“应用项目”中快速加入已有的 Claude Code、Codex 工作目录；手机上也可以添加。

进入项目后，可以新建 Claude Code、Codex 或命令行终端，继续历史对话，浏览项目文件。要在离开 App 后收到完成或确认提醒，在工作台开启“任务提醒”。

已有用户可在电脑端“设置”和 App 的“检查更新”入口更新，建议两端都更新。项目原名 Remote CLI，安装包和命令仍沿用 `RemoteCli`、`remote-cli`；1.5.7 及更早版本需手动安装一次 1.5.8 或更高版本，之后可使用应用内更新。

## 电脑与手机怎样协同

### 继续电脑上正在使用的对话

打开手机的对话窗口，消息会交给电脑上的原对话，电脑端仍然可以继续输入。默认使用共享协作，无需在电脑和手机之间反复交接。

| 电脑上运行的位置 | 手机发消息 | 手机停止回答 |
| --- | --- | --- |
| Codex 桌面应用 | 支持的原应用连接可在空闲时开始下一轮，执行中追加指令；等待确认时消息可能排队 | 停止指定的一轮，保留对话；活动目标任务不支持此操作 |
| Claude Code，包括 Claude 桌面应用中的 Code 对话 | 执行中的消息通常在下一步前送达；空闲时唤醒原对话，通常需十几秒至半分钟 | 结束当前前台命令，并在下一步前停止；仅在输出文字时需等待下一步，后台命令不受影响 |
| Codex CLI，包括编辑器终端 | 执行中的消息在本轮结束时送达；空闲时通过 Codex 队列送达 | 暂不支持从外部单独停止回答；可安全结束独立进程时会提供相应选项 |

待送达的消息逐条显示，可在交付前撤回。停止回答后，尚未交付的消息暂停，等待你继续发送或撤回。排队消息保存在电脑端，程序重启后仍保留。Codex 原应用通道的发送结果不明确时，可查询本次结果，避免重复发送。

权限请求按工具规则交给手机：Claude Code 可在电脑或手机回答；Codex 默认在电脑无人操作满一分钟后才留给手机，电脑有人操作时回到电脑确认。详细行为和等待时限见[使用说明](docs/GUIDE.md)。

### 使用完整终端

从手机新建的终端显示电脑上真实的终端画面，可输入命令、发送 Esc / Tab / Ctrl+C 等按键并回看输出。同一个终端也能在电脑上打开，两端共用画面和输入。

对电脑上独立启动的 CLI，只有能确认所属进程且可以安全结束时，才提供“接管到手机终端”：原 CLI 随之结束，同一段历史在手机终端继续。桌面应用和共享后台中的对话继续使用共享协作；支持的 Codex CLI 还可“另开一份到手机终端”，在副本中工作。

**停止回答、结束会话和关闭阅读页是不同操作。** 停止回答保留原对话；结束会话会中断对应程序；关闭手机阅读页只退出查看。当前不能从手机直接关闭桌面应用中的指定对话标签，应在原应用中关闭。

### 从手机打开桌面应用的新对话

工作台“新建任务”可在已安装的 Codex 或 Claude 桌面应用中打开项目，并预填草稿。Claude 打开的是 Claude Code 对话。**草稿仍需在电脑上确认发送**；发出后，手机页面提供“进入这段对话”。此操作可能切换电脑当前页面。

如果需要完全从手机新建、发送并推进任务，使用项目内的“新建 Claude Code”或“新建 Codex”终端入口。

## 对话、项目与任务来源

项目对应电脑上的文件夹，用于组织历史、启动新任务和限定文件查看范围。它与对话能否协作是两回事：加入项目方便管理，不是已有对话发送消息的前提。移除项目不删除文件和对话。

工作台按“等你处理、置顶、进行中、最近”整理任务，可按工具和“终端 / 应用”筛选，也可搜索项目、对话、运行位置和电脑名。

| 来源显示 | 含义 |
| --- | --- |
| 手机终端 | 由 Remote AI 管理、手机与电脑可共用的终端 |
| 命令行 | 电脑上的 CLI，会话没有确认到具体编辑器宿主 |
| Positron 的终端、VS Code 的终端、RStudio 的终端等 | 在对应编辑器的集成终端中运行 CLI |
| 编辑器的终端 | 已识别为编辑器内的 CLI，但共享后台使具体编辑器无法可靠确认 |
| Codex 桌面版、Claude 桌面版或编辑器名称 | 桌面应用或编辑器扩展中的对话 |

来源按实际运行方式判定。Codex 的 CLI 即使通过共享后台写入记录，也归入终端；不能确认具体编辑器时显示通用来源。

## 其它能力

| 能力 | 说明 |
| --- | --- |
| 多台电脑 | 每台电脑扫码一次，工作台集中显示在线状态和待处理任务 |
| 项目文件 | 只读查看代码、Markdown、笔记本、表格、PDF、图片、Word 和 PowerPoint，可保存到手机 |
| 任务提醒 | 有任务等待确认或完成时通知；需手动开启，受 Android 后台限制影响 |
| 远程设置 | 从手机切换连接线路、调整电脑端设置、发起更新；线路切换失败时恢复原线路 |
| 阅读与终端外观 | 六套配色，字体、字号和行距可调；终端提供触屏按键，支持可用的系统语音输入 |

## 兼容性与边界

- **桌面应用适配以 Windows 为主。** Codex 原对话控制目前适配 `26.1007.2314.0`，要求原应用已加载目标对话且连接可用；其它版本不启用该原生控制通道。打开新对话入口要求 Codex `26.1007.2314.0` 或 Claude `2.31226.1.0` 及以上，更新应用后需重启 Remote AI 重新识别。
- **Claude 支持的是 Claude Code 对话。** 包括命令行和 Claude 桌面应用中的 Code 对话，不包含普通 Claude 聊天的完整远控。安装钩子前已打开的 Code 对话可能需要重新打开。
- **能力随工具状态变化。** 已加入项目不保证所有按钮都可用；应用版本、连接、钩子和进程归属都会影响可用操作。无法执行时会显示原因。Codex 空闲 CLI 消息依赖支持 `codex queue` 的版本，副本功能依赖支持 `fork` 的版本。
- **对话窗口与终端显示不同。** 对话窗口展示近期消息和工具操作摘要，不能逐键控制，也不保证包含全部历史；完整输入使用终端。
- **提醒不是即时推送。** App 约每分钟检查一次，深度休眠或后台限制可能延迟通知。最多同时运行 8 个终端。
- **文件只读。** 不支持编辑、上传或删除文件；Word、PowerPoint 预览不保证与原软件分页和排版完全一致，旧式 `.doc`、`.ppt` 可下载后用其它应用打开。
- 暂无 iOS App 和 macOS 电脑端；界面目前为中文。Linux 提供后台电脑端，支持远程终端和文件查看，已有对话以查看为主，差异见 [Linux 说明](docs/LINUX.md)。

## 连接与数据安全

连接地址和密码具有远程操作电脑的权限，请妥善保管。局域网 HTTP 仅用于可信网络，外网使用 HTTPS 隧道或中转。

- Windows 电脑端用 DPAPI 加密保存密码；手机登录请求有失败次数限制。关闭“允许手机访问”可立即阻止远程访问。
- 手机只能在已添加的项目中直接新建终端，但启动的终端拥有当前电脑用户的权限，可以访问其它目录；项目列表不是命令执行的安全沙箱。
- 文件查看限定在项目目录内，不打开指向目录外的链接。已有对话交互使用电脑端发现并核实的对话及工作目录，不接受手机自行指定目录来取得控制权。
- 电脑端为 Claude Code、Codex 配置所需钩子，只修改本程序的条目并保留备份；关闭“手机处理电脑上的对话”会移除这些条目。
- 公共中转运营者在技术上能够查看经过服务器的内容。敏感任务可使用可信局域网、自己的中转，或按自身要求选择隧道服务。
- 中转保留终端最近的画面用于重连恢复，不把终端输入输出写入日志；对话窗口和文件查看内容由电脑读取后转发，中转不持久保存。
- 内置下载入口使用固定版本的 cloudflared 并校验文件完整性，校验失败不会安装。已存在或手动放入的隧道程序不因此自动替换。

项目不设账号体系，不收集使用统计。安全问题可通过 GitHub 私密漏洞报告提交。
