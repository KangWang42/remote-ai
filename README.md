## 概述

Claude Code 和 Codex 执行长任务时，会在需要授权时暂停并等待确认，完成一个阶段后也会等待下一条指令。使用者离开电脑期间，任务停在这些节点上。

Remote AI 把电脑上的这些对话带到手机上，有两种用法，可以混着用：

- **对话窗口（协作）。** 电脑上的 Claude Code 和 Codex 对话可以在手机查看记录；发送、确认和停止按钮依据原应用当前提供的能力显示。Codex 桌面适配器连接持有该对话的原窗口，空闲时发送下一句，执行中停止指定回答；电脑窗口继续使用同一段对话。CLI 和编辑器会话继续使用各自的消息及确认接口。
- **终端（完整操作）。** 从手机新建的终端显示电脑终端的实际画面，可以输入、按键和回看；同一个终端也能在电脑上打开，两端看到同一个画面。

在这之上：

- **远程处理确认请求。** 请求原文和“允许 / 拒绝”显示在任务列表的卡片上，无需进入对话或终端。
- **任务状态通知。** 开启任务提醒后，任务等待确认或执行完成时，手机收到通知。
- **按“终端 / 应用”整理。** 每张卡片在工具名后面写明它在哪里运行（手机终端、命令行、编辑器的终端、桌面版），项目写明是在终端里用的还是在应用里用的，也可以按它筛选。
- **打开 Codex 桌面项目和草稿。** 工作台的“新建任务”中，支持的 Windows 电脑会提供“在 Codex 桌面应用中打开”。选择已加入 Remote AI 的文件夹后，应用选中或建立对应项目并打开新对话输入界面，可预填草稿。内容仍需在电脑上确认发送，操作可能切换电脑当前显示的页面。此入口要求 Codex Windows 桌面应用 26.1007.2314.0 或更高版本，安装或更新应用后需重启 Remote AI；Claude 桌面应用暂不支持此入口。
- **Codex 原应用控制。** 发送和停止接口限定于 Windows Codex 26.1007.2314.0、已加入 Remote AI 的项目和原窗口已加载的对话。手机发送沿用桌面对话的模型和权限设置；等待回答时仍可写草稿。响应丢失后“查询发送结果”只读取本次回执，不重新发送。“停止回答”保留对话和应用；活动目标任务的停止、新建后自动发送及原生项目管理暂不支持。不在已添加项目里的对话，或桌面应用是其它版本时，Codex 桌面版的对话仍可在它执行时留言（做完后收到），闲置时不能发。
- **Claude Code 的控制。** Claude Code 的对话，不论开在桌面应用、编辑器还是命令行窗口里，都可以发消息、回答确认请求和停止回答，程序和对话都保留。执行中发的消息在它做完这一步后收到；闲置时由 Claude Code 自己的会话间消息送进去并唤醒它，十几秒。“停止回答”在它开始下一步之前生效，正在跑的那条命令会先跑完。停止靠 Claude Code 每一步之前运行的一个钩子实现，电脑上的 Claude Code 每一步会闪一下“running PreToolUse hook”；在装上这个钩子之前就已经打开的对话，要重新打开后才能停止。

Remote AI 不提供模型服务，也不托管账号。它使用电脑上已安装的 `claude`、`codex` 和命令行，以及电脑本地的文件、配置和登录状态。

### 与其它方案的对比

| | Remote AI | 手机 SSH 客户端 | 远程桌面 |
| --- | --- | --- | --- |
| 桌面应用里的 Claude Code、Codex 对话 | 查看记录；按适配器或 hook 能力发送、确认和停止，对话留在应用里 | 接触不到 | 可以，操作的是缩小的桌面画面 |
| 外网访问家中或公司的电脑 | 内置公网隧道和中转，无需公网 IP 和端口映射 | 通常需自行解决公网地址、端口映射或内网穿透 | 常见产品需注册账号，流量经厂商服务器 |
| 锁屏或切换网络后 | 任务不受影响，重新打开后恢复到当前状态 | 连接断开后前台任务随之结束，需另行配置 tmux 等工具 | 会话保留，需重新连接 |
| 掌握任务状态 | 列表按状态排序，可直接处理确认请求，完成后通知 | 需逐个连接查看 | 需持续查看屏幕 |
| 手机端操作 | 面向触屏设计的对话窗口、终端界面和按键行 | 取决于客户端 | 桌面画面按比例缩小，点按和输入效率低 |
| 继续电脑上已有的对话 | 所有项目最近的对话列在一起，可搜索、筛选、置顶，选择后直接继续 | 需自行记录会话并输入恢复命令 | 可以，操作方式同上 |

## 快速开始

在 [Releases](../../releases/latest) 下载 `RemoteCli-Setup-x.y.z.exe`（电脑）和 `RemoteCli-Android.apk`（手机）。

### 1. 电脑：安装并添加项目文件夹

运行安装程序，安装完成后自动打开主窗口。在“项目”页点“添加文件夹”，或将文件夹拖入窗口；“终端项目”“应用项目”两个标签列出电脑上已经有 Claude Code 或 Codex 对话的文件夹，可以直接添加。手机从这里列出的文件夹中启动终端。

<p align="center"><img src="docs/images/windows-projects.png" alt="电脑端：项目文件夹" width="62%"></p>

### 2. 电脑：选择连接方式

在“连接”页上方选择。状态变为绿色并显示二维码后，即可连接。

| 使用场景 | 连接方式 | 说明 |
| --- | --- | --- |
| 手机和电脑在同一局域网 | **局域网** | 延迟最低，无需配置。Windows 防火墙首次询问时选择“允许” |
| 外网访问，没有服务器 | **公网隧道** | 点“下载隧道程序”，数秒后获得 https 地址，无需注册账号 |
| 需要固定地址，避免重复扫码 | **公共中转** | 从列表里选一条线路即可使用，无需配置；内容经由该中转的服务器 |
| 需要固定地址，并自己掌握服务器 | **我的中转** | 在[自己的服务器上部署](docs/SELF_HOSTING.md)后添加，可保存多个 |

连接方式可随时更换，更换不会结束正在运行的终端。

<p align="center"><img src="docs/images/windows.png" alt="电脑端：连接方式和二维码" width="62%"></p>

### 3. 手机：扫码连接

安装并打开 App，点“扫码添加电脑”，扫描电脑端窗口中的二维码。连接后：

1. 电脑上开着的 Claude Code 和 Codex 对话已经列在工作台里，点开就是对话窗口，可以直接发消息。
2. 进入一个项目，选择“新建 Claude Code”“新建 Codex”或命令行以启动终端；也可从“历史对话”中选择一段继续。
3. 要处理的事按“等你处理”“置顶”“进行中”“最近”排列，可以搜索，也可以按工具和“终端 / 应用”筛选。等待确认的任务可直接在卡片上选择“允许”或“拒绝”；长按卡片可置顶、隐藏或结束。
4. 如需在离开 App 后接收通知，在工作台底部开启“任务提醒”。

App 分为三层：**工作台**（所有电脑）、**电脑**（该电脑的项目和任务）、**对话窗口或终端**。各页面的按钮和状态颜色说明见[使用说明](docs/GUIDE.md)，常见问题见[常见问题](docs/FAQ.md)。

### Linux 电脑

```bash
curl -fsSL https://raw.githubusercontent.com/KangWang42/remote-ai/main/agent-linux/install.sh | bash
```

在需要远程使用的 Linux 电脑上执行上述命令，终端显示二维码后用手机 App 扫描。无需域名、账号和 root 权限：公网地址由 Cloudflare 临时隧道提供，程序安装在当前用户目录。需要 Python 3.9 及以上和 systemd。项目文件夹可在连接后通过手机添加。使用自有域名、仅在局域网内使用、卸载和更新等内容见 [Linux 电脑端](docs/LINUX.md)。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 对话窗口 | 查看电脑上的 Claude Code 和 Codex 对话与操作记录；发送、确认和停止能力以当前适配器或 hook 状态为准，对话留在原程序中 |
| 给闲置的对话发消息 | 对话已经停下时，消息由工具自带的办法送进去并把它唤醒：Codex 用 `codex queue`，Claude Code 先唤醒再由它自己的钩子交给它。对话做完就停下，电脑上的工具看不出变化；想让消息立即送达，可以在设置里让它停下后等手机一段时间 |
| 阅读设置 | 对话窗口里的“Aa”可调字体（默认、衬线、等宽）、字号和行距 |
| 终端会话 | 显示电脑上 `claude`、`codex` 或 shell 的实际画面，支持输入、按键和回看 |
| 继续已有对话 | 列出 Claude Code 和 Codex 保存的对话，选择后在手机终端里继续 |
| 手机与电脑共用终端 | 同一终端在两端显示同一画面，均可输入，无需交接 |
| 任务状态 | 等待确认、已完成、正在执行、等待输入分别以不同颜色标示 |
| 列表内处理确认请求 | 程序请求授权时，请求原文和“允许 / 拒绝”显示在列表卡片上 |
| 终端 / 应用 | 对话和项目用文字标明是在终端里用的（手机终端、命令行窗口、编辑器里的终端）还是在应用里用的（桌面版、编辑器扩展），可按它筛选 |
| 识别已有项目 | 电脑端“项目”页的“终端项目”“应用项目”列出已有对话的文件夹，可逐个或全部添加；手机上添加项目时也会列出 |
| 管理项目和对话 | 手机上长按项目可重命名或移除；长按历史对话可置顶、隐藏或删除。删除的对话可以找回：Claude Code 的进回收站，Codex 的由 Codex 归档 |
| 在手机上切换线路和更改设置 | 人不在电脑前时，在手机上切换连接线路、更改电脑端的几项设置；新线路连不上时，电脑自动回到原线路 |
| 任务提醒 | 开启后，离开 App 期间有任务等待确认或完成时发送通知；通知栏中没有常驻通知 |
| 工作台 | 所有电脑的对话和终端按“等你处理、置顶、进行中、最近”排列，可搜索、筛选；同一段对话只列出一次 |
| 连接方式 | 局域网直连、公网隧道、公共中转、我的中转四种；后两种各有自己的线路列表。更换连接方式不会结束终端 |
| 连接状态 | 显示当前连接方式、断线重连次数和最近测得的中转延迟 |
| 文件查看 | 浏览项目文件夹，查看代码、Markdown、笔记本、表格、PDF 和图片，可保存到手机；Word 和 PowerPoint 带格式显示 |
| 外观 | 六套配色（两套明亮、四套深色），字号和行距可调；电脑端窗口使用相同的配色，默认与 App 一致 |
| 应用内更新 | 电脑端和 App 可手动检查新版本，下载并校验后安装；打开“自动检查更新”后发现新版本会提示；也可从手机发起电脑端的更新 |

## 安全

持有地址和密码即可在电脑上执行命令，应按 SSH 凭据的标准保管。

- 密码由程序随机生成，在电脑上使用 Windows DPAPI 加密保存；中转仅保存登录令牌的哈希。
- 同一来访地址连续输错 6 次密码将被锁定 15 分钟，全部地址的错误次数合计也有上限。
- 局域网直连使用未加密的 http，仅适用于可信网络。外网环境请使用公网隧道或 https 中转。
- 公网隧道的地址随机生成，但知道地址即可访问登录页，其保护仅依赖密码。
- 手机只能在已添加的项目文件夹中启动终端；终端启动后拥有与本机操作相同的权限，可以访问整台电脑。
- 给电脑上开着的对话发消息、回答确认请求，靠的是写入 Claude Code 和 Codex 自身配置的一组钩子；只增删属于本程序的条目，改动前的文件另存一份，关闭“手机处理电脑上的对话”即移除。
- 文件查看仅限已添加的项目文件夹内的内容，文件夹中指向外部的链接不会被打开。文件内容经中转传输到手机，中转不保存。
- 中转和电脑端均不将终端的输入输出写入日志；中转在数据目录中保存各终端最近的画面，用于手机重连后恢复显示。对话窗口的内容由电脑端每次现读，中转不保存。

安全问题请通过 GitHub 的私密漏洞报告提交。

## 已知限制

- 带窗口、内置中转和公网隧道的电脑端仅支持 Windows。Linux 电脑端以后台服务形式运行，可以查看电脑上开着的对话，不能从手机给它发消息，其它差异见 [Linux 电脑端](docs/LINUX.md)。暂无 macOS 电脑端。
- 暂无 iOS App。
- 界面仅提供中文。
- 任务提醒需在工作台中手动开启。App 由系统约每分钟唤醒一次进行检查，不使用服务器推送，因此通知比实际状态变化晚数十秒至一分钟，手机深度休眠时延迟更长；部分手机限制后台活动，需在系统设置中允许 App 自启动或后台运行。
- 使用公共中转时，对话和终端的内容经由该中转服务器传输，其运营者在技术上能够查看。处理敏感内容时请使用局域网直连、公网隧道或自己的中转。
- 对话窗口显示的是对话里说过的话、它边做边说的话和做过的每一步（用途、命令、输出的前几行），不是终端画面，也不能逐键输入；思考只显示工具自己留下的摘要。开在电脑终端里的对话可以从窗口右上角接到手机终端，变成完整的终端。消息在对话做完一步停下时送达；它已经停下闲置时，由工具自带的办法送进去（Codex 需要带 `codex queue` 的版本，Claude Code 一般要十几秒到半分钟）。Codex 的确认请求只在电脑无人操作时交给手机（这期间电脑上的 Codex 显示钩子正在运行，屏幕右下角有 Remote AI 的说明，动一下鼠标或键盘就回到电脑上回答），可在设置里关闭；需要先在 Codex 里确认信任这组钩子。确认请求半小时没人回答、电脑前也没有人时，工具会停下并说明它需要什么权限，之后随时可以从手机发消息让它继续并重新申请。
- 如需在手机上完整操作一段电脑上的对话，只有电脑端确认可以安全结束独立 CLI 会话时，长按卡片才会出现“接管到手机终端”，电脑上的原会话随之结束。桌面应用或共享后台持有的对话继续使用共享协作，手机消息交给原对话，避免关闭错误的程序；Codex 支持“另开一份到手机终端”时可用副本并行操作，原会话不受影响。该功能依赖支持 `fork` 的 Codex CLI（已核对版本 0.161.0）。
- 经公网连接时，按键到回显的延迟主要取决于网络往返（手机 → 中转 → 电脑 → 中转 → 手机），局域网直连延迟最低。
- 最多同时运行 8 个终端。
- 文件查看为只读，不支持在手机上编辑、上传或删除。Word 和 PowerPoint 的预览由手机页面排版：不分页，PowerPoint 的母版样式和图表可能与原文件存在差异。旧格式的 doc、ppt 不支持预览，可保存到手机后用其它应用打开。
